## What I've Built

### [flyrank-backend-milestones](https://github.com/muhammadalisajjad-dev/flyrank-backend-milestones)
Node.js/Express CRUD API refactored from monolithic to layered architecture — routes handle HTTP, services handle logic, repositories handle storage. Swagger UI docs. 7 clean commits showing progression from one-file mess to structured, swappable layers. Adding SQLite → Postgres changes exactly one file.

### Prompt Engineering Framework
Iterated a rubric-gap analysis prompt six times — role assignment, constraints, few-shot examples, step decomposition, output format, guardrails. Tested on Claude vs DeepSeek. DeepSeek reassured and missed live mismatches. Claude caught them. Result: reusable template that catches grading gaps before viva, not during it.

### Multi-Agent LLM Coordination Layer (FYP)
Middleware for detecting semantic divergence between LangGraph agents and selectively re-syncing only broken ones — not a full restart. Failure attribution with confidence scores per agent. Partial prototype. Hit resource constraints, pivoted to deeper research rather than shipping half-baked.

### OS & Systems Work (FAST-NUCES)
Built across Operating Systems, Computer Networks, and Database Systems coursework:
- **OS:** fork/exec, pipes, signals, threads, semaphores, condition variables, deadlock detection (RAG + DFS), Banker's Algorithm, lock ordering with pthreads
- **Networks:** OMNeT++ CNET simulation comparing Static Routing/RIP/OSPF, PAT configuration in Packet Tracer
- **DB:** EER diagrams, normalization through 5NF, SQL Server, C# Windows Forms integration
